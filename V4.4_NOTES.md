# FootballIQ v4.4 — Historical Evidence Chain

- Added `GET /api/v1/evidence/chain?start_event_id=...` and React EvidenceChain panel inside each historical transition.
- Resolves event IDs only from a configured local StatsBomb event JSON and separately configured historical report.
- Requires `FOOTBALLIQ_HISTORICAL_MATCH_ID` to explicitly equal the report match ID; this is an operator assertion, **not** independent validation that the file truly belongs to that match.
- Missing, duplicate or ambiguous event IDs fail closed. No fabricated evidence, no automatic current-team mapping.
