# FootballIQ v4.8 — Verified-source evidence parsing

- Evidence Chain now parses events from the **same file bytes** used to compute and check SHA-256.
- Removed independent `load_events()` use from Evidence Chain, preventing divergence between verified source and displayed evidence.
- Malformed JSON and non-array event structures fail closed with `source_unverified`.
- Added three regression tests for source/loader divergence, malformed JSON and invalid event shape.
- Backend verification: `cd backend && python -m pytest -q` → 110 passed.
- No real-provider data validation or React production build performed in this release.
