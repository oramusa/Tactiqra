# FootballIQ v4.3 — Historical Event Explorer

Added a bounded read-only API at `GET /api/v1/event-explorer/events` and a React Event Explorer inside the historical evidence panel. Filters: event type and period; cursor-based pagination; limited safe fields; no tactical claims. The explorer uses only `FOOTBALLIQ_HISTORICAL_EVENTS` (local StatsBomb JSON), **not** the selected live team or football-data.org match. Missing file returns `insufficient_data`. The event list is a pilot tool and must not be interpreted as verified match mapping.

Validation: `cd backend && python -m pytest -q` → 89 passed in this environment. React production build not run (node_modules unavailable). No live external provider verification.
