# FootballIQ OpponentIQ v5.5

New read-only GET `/api/v1/opponentiq/transition-candidates` endpoint. Identifies **rapid recovery-to-shot candidates**, not proven counterattacks. Requires explicit successful Ball Recovery or Interception among the first four events of a possession, same period, valid event timestamps, and a shot by the same team within a configurable time window (default 15 seconds). Outputs source event IDs and conservative limitations. No events file means `not_configured`; match identity remains unverified.

Tests: 136 passing backend tests in this environment. No real Barcelona–Alavés file was ingested and no React production build was verified. Sample tests use synthetic fixtures.
