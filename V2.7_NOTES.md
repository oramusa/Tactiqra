# FootballIQ v2.7 — Heatmap filters

Added historical player ID and match-period filters to the React heatmap panel and a validated period filter to the Python engine/API. The view remains a raw StatsBomb event-density map, not a tracking map, and attacking directions are not normalized. All current heatmap data is separate from the live LaLiga selection.

Backend verification: `cd backend && pytest -q` (38 passing in the working environment). React production build, PostgreSQL and full real-match validation are not verified. No commercial data license is implied.
