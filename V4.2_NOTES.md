# FootballIQ v4.2 — offline event data audit

Added `backend/data_audit.py` and `backend/test_data_audit.py`.

Without API keys or network, audit a downloaded StatsBomb events JSON:

```bash
cd backend
python data_audit.py /path/to/3773386.json --match-id 3773386 --output audit.json
python -m pytest -q
```

The audit checks JSON shape, empty files, event ID uniqueness/missingness, event location bounds (StatsBomb 120×80), event-type counts, and filename-versus-expected-ID hints. It **never** claims that filename agreement proves match identity, completeness, team mapping or tactical accuracy. Nonzero exit status 2 signals detected issues. No real match download or live API verification was performed in this version.
