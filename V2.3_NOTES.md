# FootballIQ v2.3 — Integrity verification

Adds `backend/verify_artifacts.py` to check that the source event JSON still matches the SHA-256 and byte count recorded during analysis, that the report's match ID and event count agree with the manifest, and that the review CSV can be reproduced from the report. This is **integrity checking**, not independent tactical validation.

## Commands

```bash
cd backend
python3 local_pipeline.py --events /absolute/path/to/3773386.json --match-id 3773386 --output-dir results
python3 verify_artifacts.py --events /absolute/path/to/3773386.json --results-dir results
pytest -q
```

Test status in this environment: 24/24 backend tests passed. Full LaLiga event processing, human review, PostgreSQL connection and frontend production build have not been verified.

A deliberately edited CSV will fail the integrity check; keep original exported CSV immutable and record human decisions in a separate copy.
