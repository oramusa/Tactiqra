# FootballIQ v3.2 — Independent Match Windows

Added read-only `/api/v1/opponentiq/match-windows` with separate `own_team_id`, `opponent_team_id`, `own_match_limit` (default 20), `opponent_match_limit` (default 10), and separate venue filters. Both selections are returned independently with coverage counts and match IDs.

Important: this endpoint uses the existing football-data.org LaLiga match listing, NOT StatsBomb event data. It does not yet produce tactical comparison, heatmaps or per-90 metrics. Barcelona vs Galatasaray across leagues requires a multi-league match provider, and is NOT supported by this endpoint. No production build or real-match validation is claimed.
