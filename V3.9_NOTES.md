# v3.9 — Explicit event coverage audit

Adds GET /api/v1/opponentiq/event-coverage?match_ids=1,2. Set FOOTBALLIQ_EVENT_MANIFEST to an explicit local JSON manifest. The manifest has `matches` array entries with `provider_match_id` (football-data.org ID), `event_source` (provenance label), `relative_path` (local event JSON), and `sha256` (lowercase digest). Files must be under the manifest directory. The audit verifies local file integrity, NOT the correctness of cross-provider match mapping, event completeness, or tactical analysis. Never infer cross-provider IDs from dates or team names.

The current API accepts 100 match IDs per request, while the independent match-window UI supports up to 100 matches per team. A full two-team audit requires two calls or pagination.
