# FootballIQ v2.1 — Review Quality API

After manually reviewing real match candidate events, generate `review_quality.json` using `python review_gate.py --report results/pilot_report.json --reviewed-csv results/manual_review.csv --output results/review_quality.json`.

Set `FOOTBALLIQ_PILOT_REPORT` and `FOOTBALLIQ_REVIEW_QUALITY` to absolute paths before launching FastAPI. The new read-only `/api/v1/evidence/review-quality` endpoint validates matching match IDs, count consistency, precision calculation and false recall claims. React shows sample precision only if >=10 candidates have been reviewed; otherwise it explicitly says no accuracy measure is available.

**Important:** 10 reviewed candidate events alone do not establish recall or accuracy on the full match. Data licenses, real match validation, production frontend build, and live PostgreSQL deployment remain outstanding.
