# FootballIQ v4.7 — Evidence Chain cross-provider identity gate

- Evidence Chain API now requires `FOOTBALLIQ_MATCH_IDENTITY_JSON`, a local JSON file containing `football_data`, `statsbomb`, and `team_mapping` objects.
- Requires StatsBomb match ID in the identity binding to match both report ID and `FOOTBALLIQ_HISTORICAL_MATCH_ID`.
- Invokes `verify_match_identity` to check explicitly mapped team IDs, UTC dates, full-time scores, and provider match IDs.
- Missing or malformed identity binding returns `identity_unverified` with no event items; mismatched metadata returns `identity_mismatch` with no event items.
- Evidence still returns `provisional` because metadata agreement is not provider authentication or tactical verification.
- Three new regression tests. `cd backend && python -m pytest -q`: 107 passed.
- No live API or real-match verification. React production build not checked.
