# FootballIQ v2.4 — Evidence source cross-check and CSV safety

- `verify_artifacts.py` now resolves normalized `statsbomb:<match_id>:<provider_event_id>` references against original provider event IDs, verifies that the transition start is included in its evidence, and rejects unknown evidence references.
- `review_export.py` and Evidence API CSV export prefix spreadsheet-formula-like untrusted strings to reduce formula injection risk in spreadsheet programs.
- Added regression tests for unknown source IDs, omitted start IDs, and formula escaping.
- Run: `cd backend && pytest -q`.
- The real full-match file is not included and has not been processed; no tactical precision or recall has been measured. This is not a production security audit.
