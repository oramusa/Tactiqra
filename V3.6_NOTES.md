# v3.6 — Independent scoreline trends

- Preserves independent Last N windows (default 13 and 47).
- Computes W/D/L, goals for/against per scored match, points per scored match, and chronological results from actual selected finished match scorelines.
- No invented tracking/event metrics. Missing scores are excluded and flagged.
- Requires FOOTBALL_DATA_API_KEY and provider coverage for live results.
- React build and full real-match tactical validation remain separate gates.
