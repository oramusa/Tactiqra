# FootballIQ v2.2 — CSV parity fix

The API review CSV previously selected the first 10 transitions, while the offline review CSV used a deterministic selection with shots prioritized. That could cause reviewers to assess different positions depending on how the CSV was downloaded. The API now reuses `review_export.select_review_cases` and the same column definitions, and tests verify parity.
