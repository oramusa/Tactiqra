# v3.1 — Verified attacking direction normalization (engine)

- `heatmap(..., attacking_directions={1: "left_to_right", 2: "right_to_left"})` supports explicitly verified per-period directions.
- Rotates both axes 180 degrees for right-to-left periods, maintaining team attacking orientation.
- Rejects unknown or missing directions rather than guessing.
- `compare_heatmaps` accepts independent `directions_a` and `directions_b` mappings.
- HTTP API intentionally remains raw until a trusted source for direction metadata is wired in; UI must not label its current results normalized.
- No real-match tactical validation implied by unit tests.
