# Tactiqra — Product roadmap

All three navigation modules remain in scope. Do not remove MatchIQ or CoachIQ while developing OpponentIQ.

## OpponentIQ — current priority
- Independent own-team and opponent match windows.
- Multi-match event analysis, recurring patterns, evidence-backed scouting and match preparation.

## MatchIQ — next proposed phase
- Individual match reports, player performance, shot maps, heatmaps, pass networks and event sequences.
- Tactical changes only where supported by data.

## CoachIQ — subsequent proposed phase
- Evidence-backed tactical recommendations, training plans, lineup preparation and player development.
- Coach review and control; no unsupported automated decisions.

## Shared foundation
Reuse provider adapters, match identity, event storage, evidence IDs, coverage checks and pitch visualization. Keep historical pilots distinct from current data. Tracking-dependent claims require appropriate data. Verify licensing before commercial use.

## Status
OpponentIQ is active; MatchIQ and CoachIQ remain planned, not implemented. The proposed phase order and feature scope can be refined with the product owner. No production deployment changes are authorized by this roadmap.
