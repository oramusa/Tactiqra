# FootballIQ v5.4 — possession sequence evidence

Added `GET /api/v1/opponentiq/possession-sequences`.

Reads configured local StatsBomb events JSON via the existing bounded loader. Counts unique possession IDs by possession team, possession sequences containing a shot by that team, and those containing a Goal-outcome Shot. Returns bounded evidence IDs for example possessions. It does not classify counterattacks, infer tactical transitions, claim independently verified fixture identity, or substitute event shot goals for official scores. Missing source is explicit.

Tests: `cd backend && python -m pytest -q` => 129 passed.

Actual Barcelona–Alavés JSON is not bundled; no real match calculation or React production build was performed in this release.
