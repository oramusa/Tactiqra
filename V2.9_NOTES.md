# FootballIQ v2.9 — team heatmap comparison

Implemented:
1. Separate deterministic team-comparison engine.
2. Difference grid (team A minus team B).
3. Event evidence retained for each side.
4. Explicit insufficient-data status when either side has no plotted events.
5. Same-team comparison rejected.
6. Read-only `/api/v1/heatmap/compare` endpoint.
7. Shared period, event-type and grid-size filters.
8. UI optional opponent selection and numerical difference table.
9. Five backend regression tests.
10. Verification: backend 46 passed; frontend build attempted, blocked by missing React dependencies (`node_modules`).

Limitations: raw event positions are not normalized for attacking direction; these are event counts, not tracking, player movement or tactical effectiveness. Real-match end-to-end analysis and manual review remain outstanding. The frontend build is NOT verified.

To validate locally:
- `cd backend && python3 -m pytest -q`
- `cd frontend && npm install && npm run build`
- Configure `FOOTBALLIQ_HISTORICAL_EVENTS` with a legitimately obtained full event JSON file and run the backend API.
