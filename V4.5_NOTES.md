# FootballIQ v4.5 — Evidence source integrity

- Evidence chain now requires `FOOTBALLIQ_HISTORICAL_EVENTS_SHA256` (64-character lowercase/uppercase SHA-256 hex) to match the exact configured `FOOTBALLIQ_HISTORICAL_EVENTS` file bytes.
- A missing hash, changed source file, or mismatched report `event_count` fails closed; no event evidence is returned.
- A successful response includes the verified source digest for auditing.
- To compute the digest on macOS: `shasum -a 256 /absolute/path/to/events.json`.
- SHA-256 checks file integrity **against the operator's recorded digest**, not the independent authenticity of StatsBomb or the match identity. Verify original download URL and match metadata separately.
- Does not connect to a live data provider. React production build and real-match tactical validation remain pending.
