# v4.1 — provisional multi-match tactical report aggregation

- `GET /api/v1/opponentiq/tactical-batch?team_id=7&match_ids=11,12` reads only explicitly mapped local report files via `FOOTBALLIQ_TACTICAL_REPORT_MANIFEST`.
- Manifest schema: `{"reports":[{"provider_match_id":11,"event_match_id":990,"team_id":7,"relative_path":"report.json","sha256":"<64 lowercase hex>"}]}`.
- Files must be in or below the manifest directory. SHA-256, team ID, event match ID, transition structure, and duplicate mappings are checked. These checks do NOT independently establish identity or tactical correctness.
- Missing/invalid reports are excluded; denominator is actual valid reports, not requested matches.
- UI shows provisional aggregate coverage separately for each team; does not display invented figures.
- Endpoint accepts 1–100 explicit match IDs. Current selection API remains LaLiga-only; all-available history is not implemented.
- Test coverage is synthetic; no real-match validation or independent manual review has been completed.
