# FootballIQ v4.6 — Cross-provider match identity verification

Added `backend/match_identity.py` with `verify_match_identity(football_data, statsbomb, team_mapping)` and seven tests in `backend/test_match_identity.py`.

Verification checks:
- Explicit football-data.org team ID -> StatsBomb team ID mapping for home and away teams (no fuzzy team-name matching).
- Both kickoff timestamps must be timezone-aware and resolve to the same UTC calendar date.
- Both full-time scores must be present, non-negative integers, and equal.
- Both provider match IDs must be present.
- Reject invalid/missing identifiers, mappings, dates, scores.

The output `metadata_consistent` means only that **operator-supplied metadata agree**. It does not establish provider authenticity, event-file provenance, or tactical correctness. No live provider calls or automatic mapping were added. A real cross-provider fixture and source authentication remain required. The match identity verifier is a reusable backend module; it is not yet wired into the evidence chain API.

Validation: `cd backend && python -m pytest -q` -> 104 passed. React production build not checked.
