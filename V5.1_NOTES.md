# FootballIQ v5.1 — Data Quality UI

- Added read-only `/api/v1/data-quality/historical-events` endpoint using existing `real_match_preflight.inspect_file`.
- Shows configured file structural status, event counts by team, SHA-256, and failures in Historical Evidence UI.

- Does not fetch external data, and does not claim real match validation.
- Added three API tests for missing, structurally valid, and malformed files.
