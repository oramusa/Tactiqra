# FootballIQ v2.8 — Historical heatmap catalog

- New GET /api/v1/heatmap/catalog reads the configured historical event JSON and returns real source team names, players and event types.
- Heatmap UI uses team/player dropdowns rather than requiring users to discover StatsBomb IDs manually.
- Catalog returns insufficient_data when no local source is configured; no invented team list.
- Does not merge historical StatsBomb teams with live football-data.org identifiers.
- Does not claim tracking heatmap or real-match tactical validation.
- Test with `cd backend && pytest -q`.
